## What is .gitignore?
The `.gitignore` file tells git which files to ignore when comitting your project to the Github repository. We may want to ignore certain files for multiple reasons (e.g., files containing sensitive data). 
This has been added to the repository by creating the `.gitignore` locally and pushing it into this remote repository.

## What is requirements.txt?
This file is written by the owner of the repository letting those who read it see the requirements of the repository. It lists all the project’s dependencies, usually containing a list of packages or libraries (e.g., in python) needed to work on a project. 
This has been added to the repository by creating the requirements.txt locally and pushing it into the remote repository on Github _(see below)_
